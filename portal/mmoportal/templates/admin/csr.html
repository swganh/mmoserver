In-game staff tools

What staff can do inside the game today, and who can. The servers give staff two things: the account's CSR flag, and the hidden admin profession whose skills unlock the admin slash commands. Both are set on an account's page and apply from the character's next login.

Admin commands that work

Type them in the game's chat box. Each needs the admin skill shown, given to the character on its account's page. These have server code but have not been through the client tests yet (docs/TEST_PLAN.md).
