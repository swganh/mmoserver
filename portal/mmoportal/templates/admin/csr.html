In-game staff tools

What staff can do inside the game today, and who can. The servers give staff two things: the account's CSR flag, and the hidden admin profession whose skills unlock the admin slash commands. Both are set on an account's page. They apply when the character is next loaded: the zone server keeps a character in memory for 5 minutes after it logs out (Zone_Player_Logout), so log out and stay out for 5 minutes, or restart its zone server, before trying them.

Admin commands with server code

The servers carry these out for a character with the admin skill shown, given on its account's page. Whether the game client sends them is another matter: only the three broadcasts are commands the client knows, and it marks them for god level 5. Where the client takes a character's god level from is being tested (it may be the CSR flag's value). The other four are not in the client's command table, so typing them does nothing until the client can be made to send them.
